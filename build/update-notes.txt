本次更新合集（0.60.21–0.60.55）：

汉化
- 参照柠娜思路的完整汉化：FTB Quests 任务书 lang/SNBT、通用 lang、模组配置说明、模组 JAR 内 en_us、Patchouli 手册、光影 shaders/lang；输出补充资源包或原子替换光影 zip，应用前备份，支持 diff、逐条校对、中英对照和后台翻译。
- 内置 CFPA 社区术语库 390,882 条（CC BY-NC-SA 4.0），按批次文本自动命中，优先级为用户术语 > 社区词库 > 基础术语；不写入用户术语文件。

下载与安装
- 修复大文件 If-Range 导致退回单连接、最后 2 MB 卡住；原版客户端 38 MB 从 76–134 秒降到 7–15 秒。
- 整合包/Mod ≥8 MB 启用镜像/官方双线路、尾段细分、慢分片重连和源站测速；跨实例同 SHA1 文件硬链接/复制复用。
- CurseForge 清单解析并发 24 路并缓存；Forge/NeoForge 安装器预下载运行库并走镜像，1.20.1 Forge 安装约 45 秒。
- CurseForge 文件新增 MCI 国内镜像：整合包、模组、资源包和服务端包优先尝试 `mod.mcimirror.top`，并与 `mediafilez` 官方 CDN 双线分片、失败自动回退；关闭「文件镜像加速」后只走官方线路。
- CurseForge 客户端版本过滤 ServerFiles/ServerPack，并支持下载全部服务端包；Quick Play 一键进服。

功能与界面
- 原版实例、统一备份管理、实例迁移/克隆、截图仓库、游戏时长周报、JVM 预设、服务端包生成与真实启动验证。
- KubeJS 工作台：编辑器、历史、AST 释意、语义预检、问题一键修复、配方/标签/机器/祭坛生成、已有配方导入、AI 问答与选段改写、真实服务端运行验证。
- 品牌改为「月月月启动器」，界面减法、页面切换动效、字号上调、多图轮换背景、居中标题栏与「更多」页重排；修复省内存模式强制软件渲染导致的卡顿。

更新与诊断
- 新增下载诊断日志：整合包安装/升级会自动记录线路测速、DNS 地址、主压缩包/清单/模组批量阶段耗时、每个文件来源与速度、重试和慢速换源；「更多 → 日志与诊断 → 下载日志」可查看、复制、导出 txt，并可一键「网络体检」对比 MCI / mediafilez / edge。日志保留最近 30 条，失败优先保留，不含账号、令牌、代理地址和完整本地路径。
- 安装包改名：本地文件为 `月月月启动器-<版本>-setup.exe`；GitHub Release 只保留 ASCII 附件名，因此公开下载文件为 `Yueyueyue-Launcher-<版本>-setup.exe`，发布页显示中文标签。更新器优先识别中文名与拼音名，并继续兼容 `Windletter-Launcher-*` 旧名，0.60.51 及更早版本可直接升级。
- `npm run dist` 强制注入 CurseForge Key 和默认更新源；缺少 Key 时构建失败，避免发出不带 Key 的安装包。
